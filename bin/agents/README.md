# GDS Agents

GDS Agents is a native GPUI session workspace for an independently running BAS service, featuring multi-session conversations, streaming Markdown, interactive permission prompts, searchable history, and an embedded local terminal.

> GDS Agents is currently under active development and is not yet packaged in end-user distro releases.

```sh
just dev agents
just dev agents --compact
```

See [GDS Agents Overview](../../docs/apps/agents/README.md) and [Agents & BAS Protocol](../../docs/development/agents-protocol.md) for architecture and developer documentation.
