# GDS Agents

GDS Agents 是面向独立运行的 BAS 服务的原生 GPUI 会话工作区，提供多会话对话、流式 Markdown 渲染、交互式权限确认、历史记录检索以及内置本地终端。

> GDS Agents 目前仍处于早期开发阶段，尚未纳入面向终端用户的发行版安装包。

```sh
just dev agents
just dev agents --compact
```

架构与开发说明见 [GDS Agents 文档](../../../../../docs/apps/agents/README.md)。
